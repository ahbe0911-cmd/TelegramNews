# نبض خبر | Telegram News

اپلیکیشن اندروید Flutter با رابط فارسی RTL، Riverpod و Material 3. این بسته **سورس پروژه** است؛ APK ساخته‌شده یا سرویس Firebase مستقرشده نیست.

## کانال انتخاب‌شده

کانال هدف [@ahbe1400](https://t.me/ahbe1400) است و لینک آن در تنظیمات برنامه نمایش داده می‌شود. این تنظیم به‌تنهایی اخبار زنده را فعال نمی‌کند؛ ربات، Firebase و وب‌هوک باید طبق مراحل زیر متصل شوند.

## آنچه پیاده‌سازی شده

- هدر گرادیان آبی–بنفش، تاریخ شمسی کامل، ساعت ثانیه‌ای، نماد مرکزی، تنظیمات و تم تاریک/روشن پایدار.
- کارت‌های ۱۶ پیکسلی، تصویر، متن، برچسب مهم، Shimmer، Ripple، انیمیشن ورود و Hero در جزئیات.
- دریافت صفحه‌ای، Pull-to-Refresh، بررسی خبرهای تازه هر ۳۰ ثانیه در پیش‌زمینه، جست‌وجوی سمت سرور، حالت خالی، خطا و تلاش دوباره.
- نمایش متن فارسی و فرمت‌های Bold/Italic/لینک، انتخاب و کپی متن، اشتراک‌گذاری و بازکردن پست در تلگرام.
- Firebase Cloud Functions: وب‌هوک امن Telegram، ذخیره Firestore، ذخیره تصویر خصوصی در Storage و API عمومی فقط‌خواندنی.
- FCM با payload داده‌ای؛ نمایش محلی با تصویر و صدای اختصاصی، بازکردن مستقیم خبر از اعلان حتی در شروع سرد، تنظیم روشن/خاموش، مهم و ساعات بی‌صدا.
- فونت واقعی موقت DejaVu Sans با پوشش فارسی و مجوز همراه؛ فایل صفر بایتی یا فونت نامعتبر استفاده نشده است.
- دو مسیر GitHub Actions برای APKهای arm64-v8a، armeabi-v7a و x86_64.

## تصمیم سازگاری اندروید

| مسیر | Flutter | Android | کاربرد |
| --- | --- | --- | --- |
| modern | جدیدترین stable در زمان اجرای Actions | API 24 به بالا | مسیر اصلی |
| legacy | 3.24.0 | API 21 به بالا | حفظ درخواست Android 5 |

Flutter جدید با API 21 سازگار نیست؛ بنابراین یک APK واحد با هر دو شرط تولید نمی‌شود. مسیر قدیمی از Firebase Core 2.32.0، Messaging 14.9.4 و Notifications 17.2.4 استفاده می‌کند. مسیر جدید از Core 4.x، Messaging 16.x و Notifications 19.5.0 استفاده می‌کند. این نسخه‌های وابستگی برای حفظ API کد انتخاب شده‌اند، نه به ادعای آخرین‌بودن همه پکیج‌ها. رفع وابستگی‌ها و سازگاری نهایی باید در CI تأیید شود. برای خروجی تکرارپذیر، پس از بیلد موفق `pubspec.lock` را از artifact بردارید و نسخه Flutter مسیر modern را نیز ثابت کنید.

## ساخت APK در GitHub — بدون Firebase هم ممکن است

۱. محتویات پوشه پروژه را در ریشه مخزن قرار دهید، به‌طوری که `pubspec.yaml` و `.github/workflows/build-apk.yml` در ریشه باشند. **پوشه مخفی `.github` را حتماً آپلود کنید.**
۲. شاخه `main` را push کنید، یا در تب **Actions → Build APK → Run workflow** اجرا کنید.
۳. پس از سبزشدن اجرا، از بخش **Artifacts** فایل `release-apk-modern` یا `release-apk-legacy` را دانلود و ZIP آن را باز کنید.
۴. برای اغلب گوشی‌های جدید، `app-arm64-v8a-release.apk` مناسب است. برای Android 5 نسخه legacy و معماری مناسب گوشی را انتخاب کنید.
۵. بدون تنظیمات سرویس، برنامه با برچسب «حالت نمایشی» و خبرهای نمونه باز می‌شود. هیچ خبر نمونه‌ای به‌عنوان خبر واقعی معرفی نمی‌شود.

پوشه Android توسط `scripts/prepare_android.py` از Flutter همان مسیر ساخته می‌شود. این کار Gradle Wrapper، Activity، آیکون لانچر و سایر فایل‌های میزبان را تولید می‌کند؛ پروژه به Wrapper جعلی متکی نیست. تنظیمات سفارشی Manifest، minSdk، desugaring، صدا و آیکون اعلان سپس اعمال می‌شوند. نماد مرکزی فعلاً Iconsax و آیکون لانچر پیش‌فرض Flutter است؛ لوگوی اختصاصی برند در این بسته طراحی نشده است.

## امضای APK

بدون secrets امضا، APK نوع release با کلید تست تولید می‌شود و برای نصب آزمایشی مناسب است. کلید تست بین اجراهای CI ثابت نیست؛ برای آپدیت بدون حذف نسخه قبلی یا انتشار، کلید ثابت خود را بسازید و این GitHub Secrets را وارد کنید:

- `KEYSTORE_BASE64`: محتوای base64 فایل keystore
- `KEYSTORE_PASSWORD`
- `KEY_PASSWORD`
- `KEY_ALIAS`

کلیدها را در کد، فایل public یا پیام گفتگو نگذارید. اسکریپت تنظیمات آن‌ها را از محیط می‌خواند و چاپ نمی‌کند. نگه‌داری نسخه پشتیبان کلید امضا بر عهده مالک پروژه است.

## اتصال واقعی کانال و اعلان‌ها

### ۱. پیش‌نیازها

- دسترسی مدیریتی به کانال عمومی؛ یک ربات ساخته‌شده با BotFather را به کانال اضافه کنید (برای کانال معمولاً به‌صورت مدیر).
- یک پروژه Firebase با برنامه Android به شناسه دقیق `ir.channel.telegram_news`.
- Firestore در حالت Native و Cloud Storage فعال؛ برای این Functions/Storage معمولاً پروژه باید روی پلن Blaze با حساب پرداخت باشد. این معماری سرویس رایگان تضمین‌شده نیست.
- Node.js 22، Firebase CLI و Python 3 روی کامپیوتر راه‌اندازی.

### ۲. آماده‌سازی Firebase

```bash
npm install -g firebase-tools
firebase login
firebase use --add
cd functions
npm install
npm test
cd ..
```

فایل `functions/.env.example` را به `functions/.env.PROJECT_ID` کپی کنید. کانال `@ahbe1400` در نمونه تنظیمات قرار گرفته است. آدرس عمومی API پروژه خود را وارد کنید:

```text
TELEGRAM_CHANNEL_ID=@ahbe1400
PUBLIC_API_BASE_URL=https://europe-west1-PROJECT_ID.cloudfunctions.net/api
```

سرور با `getChat` نام `@ahbe1400` را به شناسه عددی تبدیل و سپس شناسه پست را کنترل می‌کند. می‌توانید به‌جای نام کاربری، شناسه عددی واقعی کانال را تنظیم کنید تا وابستگی به تغییر نام کاربری حذف شود. این پروژه مخصوص **یک کانال** است.

توکن ربات و رمز وب‌هوک را فقط با فرمان‌های تعاملی زیر در Secret Manager وارد کنید:

```bash
firebase functions:secrets:set TELEGRAM_BOT_TOKEN
firebase functions:secrets:set TELEGRAM_WEBHOOK_SECRET
```

رمز وب‌هوک باید تصادفی، حداقل ۳۲ کاراکتر و شامل حروف/اعداد ASCII، `_` یا `-` باشد. همان رمز برای ثبت وب‌هوک لازم است.

```bash
firebase deploy --only functions,firestore:rules,storage
python3 scripts/set_webhook.py
```

اسکریپت آخر توکن و رمز را به‌صورت مخفی می‌گیرد. آدرس تابع وب‌هوک را از خروجی deploy کپی کنید. برای این منطقه معمولاً:

```text
https://europe-west1-PROJECT_ID.cloudfunctions.net/telegramWebhook
```

### ۳. تنظیمات GitHub

در **Settings → Secrets and variables → Actions**:

| نوع | نام | مقدار |
| --- | --- | --- |
| Secret | GOOGLE_SERVICES_JSON | کل محتوای فایل Android دریافت‌شده از Firebase |
| Variable | API_BASE_URL | `https://europe-west1-PROJECT_ID.cloudfunctions.net/api` |
| Variable اختیاری | APP_TITLE | نام دلخواه برنامه |

Actions را دوباره اجرا کنید. فایل google-services در زمان ساخت ساخته می‌شود؛ توکن ربات هیچ‌وقت داخل APK قرار نمی‌گیرد. تغییر APP_TITLE عنوان داخل برنامه را عوض می‌کند؛ نام لانچر فعلاً در اسکریپت Android «نبض خبر» است.

### ۴. آزمایش واقعی

- یک پست تازه شامل متن فارسی، Bold، لینک، عکس و `#مهم` منتشر کنید.
- API `/posts` باید آن را برگرداند؛ گوشی با اینترنت و Google Play Services باید خبر و اعلان را دریافت کند.
- روی اعلان در حالت باز، پس‌زمینه و پس از بسته‌شدن معمولی برنامه بزنید؛ باید همان خبر باز شود.
- مجوز اعلان Android 13+، حالت «فقط مهم»، خاموش‌کردن اعلان، ساعات بی‌صدا عبوری از نیمه‌شب و بازکردن مجدد برنامه را بررسی کنید.
- ویرایش پست باید متن ذخیره‌شده را به‌روز کند، ولی اعلان جدید ایجاد نکند. جزئیات بازشده snapshot همان خبر است؛ برای دیدن ویرایش، به فهرست برگردید و refresh کنید.

## محدودیت‌های واقعی و صریح

- Bot API به آرشیو گذشته کانال عمومی یا هر کانالی که ربات عضو آن نیست دسترسی نمی‌دهد. دریافت از زمان اتصال شروع می‌شود؛ backfill آرشیو در این نسخه پیاده نشده است.
- Bot API تعداد بازدید تلگرام را نمی‌دهد. مقدار `views` برابر null است و UI «—» نشان می‌دهد؛ عدد ساختگی نمایش داده نمی‌شود. برای آرشیو/بازدید واقعی، سرویس TDLib با احراز هویت کاربر و مدیریت session جدا لازم است.
- جست‌وجو در هر درخواست حداکثر ۱۰۰ رکورد ذخیره‌شده را بررسی می‌کند؛ با «خبرهای بیشتر» یا «جست‌وجو در خبرهای قدیمی‌تر» ادامه می‌یابد. برای آرشیو بزرگ، موتور جست‌وجوی جدا توصیه می‌شود.
- رسانه عکس ذخیره و نمایش داده می‌شود. ویدئو، آلبوم گروه‌بندی‌شده، فایل، نظرسنجی و رندر سفارشی emoji در این نسخه کامل پشتیبانی نمی‌شوند؛ لینک پست برای مشاهده در تلگرام موجود است. حذف پست در تلگرام به‌صورت خودکار از آرشیو حذف نمی‌شود.
- برای اعمال فیلترها و ساعات بی‌صدا در گوشی، FCM داده‌ای با اولویت بالا استفاده شده است. Force Stop، نبود Google Play Services، محدودیت باتری، اینترنت و سیاست Android ممکن است تحویل را تأخیر دهند یا متوقف کنند. تضمین اعلان در لحظه یا بعد از Force Stop وجود ندارد.
- ساعات بی‌صدا اعلان را حذف نمی‌کنند؛ آن را بدون صدا و لرزش نمایش می‌دهند. شروع=پایان یعنی تمام روز. تنظیمات کانال اعلان سیستم‌عامل بر تنظیمات اپ اولویت دارند.
- اعلان‌های تکراری احتمالی تحویل حداقل یک‌باره FCM/Functions از شناسه ثابت پست استفاده می‌کنند و کارت اعلان را جایگزین می‌کنند؛ تحویل دقیقاً یک‌باره تضمین نشده است.
- بازشدن مستقیم خبر از اعلان پیاده شده؛ Android App Links برای یک دامنه اختصاصی عمومی در این بسته تنظیم نشده است.
- API عمداً عمومی و فقط‌خواندنی است، چون محتوا عمومی است. Firestore و Storage برای دسترسی مستقیم کلاینت بسته‌اند. maxInstances و محدودیت صفحه مصرف را محدود می‌کنند، ولی جایگزین سهمیه/کنترل هزینه یا محافظت کامل در برابر سوءاستفاده نیستند. تصویرهای نسخه‌های قدیمی را در نگه‌داری دوره‌ای Storage پاک کنید.
- هیچ سرویس ابری، ربات، حساب پرداخت یا مخزن GitHub از طرف این بسته ایجاد یا تغییر داده نشده است.

## فونت سفارشی

فایل‌های زیر را با فونت دارای مجوز خود جایگزین کنید؛ نیازی به تغییر کد نیست:

```text
assets/fonts/CustomFont.ttf          Regular 400
assets/fonts/CustomFont-Bold.ttf     Bold 700
assets/fonts/CustomFont-Light.ttf    Light 300
```

نام خانواده در `pubspec.yaml` و Theme برابر `CustomFont` است. فعلاً Light از همان فونت Regular استفاده می‌کند؛ وزن Light واقعی را بعداً جایگزین کنید. برای فایل OTF پسوند و مسیر را در pubspec نیز تغییر دهید. مجوز DejaVu موقت در همین پوشه موجود است.

## اجرای محلی

با Flutter stable برای modern یا Flutter 3.24.0 برای legacy:

```bash
python3 scripts/prepare_android.py --profile modern
python3 scripts/configure_build.py
flutter pub get
flutter analyze --no-fatal-infos
flutter test
flutter run --dart-define-from-file=config.json
flutter build apk --release --split-per-abi --dart-define-from-file=config.json
```

اسکریپت configure_build تنظیمات را از متغیرهای محیطی هم‌نام CI می‌گیرد؛ در نبود آن‌ها حالت نمایشی ایجاد می‌کند. برای کار محلی می‌توانید config.json را بر اساس config.example.json ویرایش کنید. اگر Firebase را دستی متصل می‌کنید google-services plugin نیز باید توسط همین اسکریپت اعمال شود. برای تغییر پروفایل از یک کپی تازه پروژه استفاده کنید؛ اسکریپت عمداً Android موجود را بازنویسی نمی‌کند.

## وضعیت اعتبارسنجی این تحویل

- هشت آزمون Node برای احراز هویت، محدودکردن کانال، HTML امن، آفست UTF-16، ویرایش/عکس و cursor اجرا و موفق شدند.
- syntax بخش Node و Python بررسی شد؛ تمام فایل‌های Dart با Dart 3.5 format شدند و از parser عبور کردند.
- آزمون‌های Flutter برای تاریخ، ساعات بی‌صدا، race جست‌وجو، صفحه‌بندی و بازیابی خطا نوشته و به CI اضافه شدند؛ در محیط تهیه بسته Flutter SDK در دسترس نبود و این آزمون‌ها یا بیلد APK اجرا نشده‌اند.
- UI روی دستگاه/شبیه‌ساز، Firebase واقعی، امضای نهایی و اعلان انتهابه‌انتها هنوز تأیید نشده‌اند. این ZIP را APK نهایی آزمایش‌شده تلقی نکنید.
